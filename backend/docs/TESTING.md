# راهنمای تست اتصال

## ۱) تست خودکار (بدون کلید)
```bash
npm test
```
۱۷ تست: مسیر موفق، نشت نکردن کلید، اعتبارسنجی، سقف توکن، نگاشت خطاهای 400/401/402/429/500، Retry، Timeout، Rate limit، کلید قطع اضطراری، توکن کلاینت، سقف بودجه.

## ۲) تست واقعی با GapGPT
بعد از تنظیم `GAPGPT_API_KEY`:
```bash
node scripts/test-connection.js https://<آدرس-بک‌اند> [CLIENT_TOKEN]
```
چهار مرحله: `health` ← `status` ← `model exists on your account` ← `real chat request`. اگر مرحلهٔ مدل FAIL شد، `DEFAULT_MODEL` را با مدلی که در `/v1/models` می‌بینید عوض کنید.

یا با curl:
```bash
curl -s https://<آدرس>/health
curl -s https://<آدرس>/v1/models
curl -s https://<آدرس>/v1/chat -H 'content-type: application/json' \
  -d '{"messages":[{"role":"user","content":"سلام"}],"max_tokens":30}'
```

## ۳) تست از داخل اپ
دستیار هوشمند ← آیکون تنظیمات ← آدرس HTTPS بک‌اند را وارد کنید ← «ذخیره و آزمایش اتصال». پیام باید بگوید سرور وصل است و مدل در حساب موجود است.

## ۴) بررسی ایمنی
- در لاگ سرور هیچ متن پیام یا کلیدی نباشد (فقط متد، مسیر، کد وضعیت، زمان و تعداد توکن).
- `AI_ENABLED=0` و ری‌استارت: اپ باید پیام «غیرفعال از سمت سرور» نشان دهد.
- کلید را عمداً اشتباه بگذارید: اپ باید پیام «سرور اجازهٔ استفاده ندارد» بدهد، نه متن خطای خام.
