# KhodroYar AI Backend

> از نسخهٔ 5.1.10 حالت پیش‌فرض دستیار داخل اپ **محلی و بدون API** است و به این سرور نیاز ندارد.
> این بک‌اند فقط برای حالت آنلاین اختیاری است. Secretهای امضای APK جای کلید/استقرار این سرور را نمی‌گیرند.
> در حالت «بک‌اند شخصی خودرویار»، اپ آدرس همین سرور واسط را می‌خواهد، نه آدرس خود GapGPT.
> از نسخهٔ 5.1.11 گزینهٔ جداگانهٔ «اتصال مستقیم GapGPT» هم هست؛ آن گزینه API Key شخصی را رمزنگاری‌شده روی گوشی نگه می‌دارد و به این سرور نیاز ندارد.

بک‌اند سبک و مستقل برای «دستیار هوشمند خودرویار». برنامهٔ اندروید فقط با این سرور حرف می‌زند و کلید GapGPT **فقط روی همین سرور** (در Environment Variables) نگهداری می‌شود.

```
اپ اندروید  --HTTPS-->  این بک‌اند  --HTTPS + API Key-->  GapGPT (OpenAI-compatible)
```

- بدون هیچ وابستگی npm (فقط Node.js 18.17 به بالا)
- محدودیت نرخ، محدودیت اندازهٔ پیام و توکن خروجی، سقف روزانهٔ هزینه، کلید قطع اضطراری
- کلید هرگز در پاسخ‌ها، لاگ‌ها یا خطاها نمی‌آید؛ متن پیام‌ها هم لاگ یا ذخیره نمی‌شود
- هیچ Firebase یا سرویس تبلیغاتی ندارد

## اجرای محلی (۳ دستور)

```bash
cd backend
cp .env.example .env        # سپس GAPGPT_API_KEY را در همین فایل (فقط روی سیستم خودتان) بنویسید
npm start
```

تست خودکار (بدون نیاز به کلید یا اینترنت، با سرور شبیه‌سازی‌شده):

```bash
npm test
```

تست اتصال واقعی (با کلید واقعی؛ چند توکن اعتبار مصرف می‌کند):

```bash
node scripts/test-connection.js http://127.0.0.1:8787
```
