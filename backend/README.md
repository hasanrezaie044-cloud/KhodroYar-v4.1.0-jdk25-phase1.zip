# KhodroYar legacy AI proxy

این سرور فقط برای سازگاری کلاینت‌های قدیمی نگه داشته شده است. **اندروید۵.۶.۳ به آن dispatch یا fallback ندارد.** اتصال‌های فعال برنامه دقیقاً دستیار آفلاین، OpenRouter، Gemini، Groq، Claude، Fireworks AI و GPT هستند؛ راهنمای فعلی در [مدیریت مدل](../docs/AI-MODEL-MANAGEMENT.fa.md) و [اتصال‌ها](../docs/AI-PROVIDERS.fa.md) است.

## قرارداد فعلی سرور

- Node.js۱۸.۱۷ به بالا؛ بدون وابستگی runtime npm.
- کلید upstream فقط روی سرور و در هدر HTTPS خروجی است؛ در APK، پاسخ، لاگ یا خطا قرار نمی‌گیرد. محتوای پیام‌ها لاگ/ذخیره نمی‌شود.
- سقف محلی درخواست/روز/نرخ/توکن و محدودیت تعداد/طول پیام/تاریخچه حذف شده‌اند. متغیرهای محیطی قدیمی این سقف‌ها نادیده گرفته می‌شوند. `/admin/usage` فقط شمارندهٔ بدون payload است، نه مجوز مصرف.
- درخواست عادی `max_tokens` ندارد؛ اگر کلاینت صریحاً عدد مثبت بدهد، همان عدد بدون default/clamp محلی به upstream می‌رود. context، هزینه و سهمیهٔ واقعی متعلق به سرویس‌اند.
- برای هر درخواست فقط **یک تلاش** به upstream انجام می‌شود؛ حتی۵۰۳،۴۲۹، خطای شبکه یا رد `response_format` باعث retry یا تغییر مدل نمی‌شوند.
- اعتبارسنجی پروتکل، انتخاب مدل مجاز سرور، احراز هویت، timeout شبکه و حد۳۲MiB برای حفاظت حافظه باقی‌اند؛ حد بدنه سهمیهٔ مصرف نیست.
- `CLIENT_TOKEN`/`ADMIN_TOKEN` و کلید قطع اضطراری `AI_ENABLED=0` حفظ شده‌اند. توکن ثابتِ داخل یک APK راز قابل اتکا نیست؛ سرورِ بدون دسترسی محافظت‌شده را عمومی نکنید.
- endpointها، قیمت، مجوز منطقه یا موجودی حساب به‌صورت زنده در توسعه تأیید نشده‌اند. Firebase، تبلیغ یا analytics نداریم.

## راه‌اندازی مستقل سرور قدیمی

```bash
cd backend
cp .env.example .env
# فقط روی سرور/سیستم خودتان متغیرها را تنظیم کنید؛ فایل یا کلید را در Git/chat نفرستید.
npm start
```

`GAPGPT_BASE_URL` ریشه، `/v1` یا مسیر کامل `/v1/chat/completions` را می‌پذیرد و دقیقاً یک endpoint ساخته می‌شود؛ redirect با هدر کلید ممنوع است. `DEFAULT_MODEL` فقط پیشنهاد اولیه است، نه تضمین موجودبودن یا رایگان‌بودن؛ `GET /v1/models` فهرست حساب را می‌خواند.

## تست بدون مصرف اعتبار

```bash
npm test
```

تست‌ها HTTP/upstream ساختگی دارند و کلید، خرید، فعال‌سازی billing یا inference واقعی لازم ندارند. اسکریپت تاریخی `scripts/test-connection.js` می‌تواند درخواست واقعیِ مصرف‌کنندهٔ اعتبار بفرستد؛ جزو تست توسعه نیست و بدون اجازهٔ جداگانه اجرا نشود.
