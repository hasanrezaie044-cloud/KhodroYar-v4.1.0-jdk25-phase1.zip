Modifications by KhodroYar:
- The pretrained Persian ALBERT encoder is retained, frozen, with no user-data training.
- The original fill-mask head is not used. An app-specific supervised intent head is fitted using the original authored examples in tools/offline-albert/intents.json.
- Export to ONNX opset 17; shared-weight Identity aliases resolved; selected matrices/embeddings dynamically quantized to signed int8.
- Maximum 64 tokens. Unsupported, long, uncertain or unsafe requests fall back/abstain rather than being silently truncated.
This is a narrow task classifier, not a general chatbot, medical adviser, speech recognizer or authorization mechanism. Amounts, dates, calculations, app data and write approval are NOT produced by the model.

The installed app performs this model's inference entirely on the device. It has no runtime model download, API key or telemetry. Existing optional online AI/traffic features remain separately configured and consented; this notice does not describe the whole app as permanently offline.

Cafe Bazaar update checking uses its documented own-package bound service. Only the app package name is supplied, not chat text, financial data, location or credentials. The listing opens only after a user tap. No self-installation is performed.
