# به‌روزرسانی خودرویار از کافه‌بازار — از ۵.۵.۶ / کد ۷۳

## رفتار برنامه

- بعد از ورود/تکمیل پروفایل، بررسی نسخه جدا از UI اجرا می‌شود؛ ورود منتظر بازار نمی‌ماند.
  هنگام بازگشت نیز بررسی ممکن است؛ بررسی‌های خودکار حداقل ۵ دقیقه فاصله دارند.
- پرسش از **نسخهٔ منتشرشده در بازار** است، نه GitHub، نام نسخه، فایل محلی یا سرور شخصی.
  پاسخ عددیِ مثبتِ بزرگ‌تر از `BuildConfig.VERSION_CODE` اعلان می‌دهد. خطا/۰/−۱ معادل
  «نسخهٔ جدید» یا «قطعاً آخرین نسخه» نیست. timeout شش ثانیه و unbind در پایان/لغو رعایت می‌شود.
- «به‌روزرسانی از بازار» فقط با اقدام کاربر، URI
  `bazaar://details/modal?id=com.khodroyar.app` را با package صریح `com.farsitel.bazaar`
  باز می‌کند؛ لینک سازگار `bazaar://details?...` و در نبود برنامه، صفحهٔ HTTPS همان بسته
  در بازار fallback هستند. برنامه APK را دانلود/نصب نمی‌کند؛ ادامهٔ نصب در خود بازار است.
- «بعداً» همان کد را ۲۴ ساعت به تعویق می‌اندازد؛ کد بالاتر دوباره مجاز است. قفل‌شدن ساعت
  به عقب تعویق دائمی نمی‌سازد. چرخش/بازترکیب UI درخواست تکراریِ بی‌وقفه نمی‌سازد.
- تنظیمات ← درباره: بررسی دستی (بدون محدودیت تعویق خودکار) و بازکردن صفحهٔ بازار.
  نبود بازار/اینترنت/سرویس به‌روزرسانی، ورود و کارهای معمول برنامه را مسدود نمی‌کند.
- فقط package visibility مشخص بازار اضافه شده؛ `QUERY_ALL_PACKAGES`، مجوز نصب، دسترسی
  فایل عمومی، حساب توسعه‌دهنده یا توکن بازار لازم نیست.

## انتشار توسط مالک

1. همین بستهٔ `com.khodroyar.app` با **همان گواهی اصلی** منتشر شود؛ APK تحویلی را دوباره
   امضا نکنید. امضای متفاوت به‌روزرسانی روی نصب فعلی نیست.
2. کد فعلی ۷۳ است؛ انتشار بعدی باید کد بالاتری داشته باشد. شمارهٔ نام نسخه معیار نیست.
3. تا تأیید/انتشار نسخهٔ بالاتر در بازار، اعلان واقعیِ نسخهٔ جدید انتظار نمی‌رود. فروشگاه
   تصمیم نهایی دربارهٔ دسترس‌پذیری/سازگاری دستگاه و اجازهٔ نصب را می‌گیرد.
4. این تغییر به نسخهٔ ۵.۵.۵ قدیمی از راه دور اضافه نمی‌شود؛ کاربران ابتدا باید نسخه‌ای
   شامل این قابلیت را نصب کنند، سپس انتشارهای بالاتر اعلان خواهند داشت.
5. CI/عامل به حساب توسعه‌دهندهٔ بازار چیزی بارگذاری نمی‌کند؛ انتشار بازار با خود مالک است.

## رابط رسمی و آزمون‌ها

قرارداد سبک AIDL (بدون وابستگی SDK/JitPack) از منبع رسمی
[CafeBazaar/BazaarUpdater](https://github.com/cafebazaar/BazaarUpdater) با commit ثابت
`670bdfd0cf7bd57c03ec503a78e1bcddd8fe29b6` پیروی می‌کند: اولین دو متد با همان ترتیب
تراکنش، bind action رسمی، package صریح، URI modal و آستانهٔ نسخهٔ بازار `2400700`.
برای بازار جدید `getRemoteVersionCode`، برای قدیمی `getVersionCode` استفاده می‌شود.
فراخوانی Binder روی IO است؛ انقضا/قطع اتصال پاسخ دیررس را به UI وارد نمی‌کند. متن کامل
Apache-2.0 در تنظیمات/منبع بسته شده است؛ این SDK کامل و نصب‌کنندهٔ خودکار نیست.

تست‌های JVM سیاست کد/تعویق/URI، تست بومی نبود بازار و fallback/دکمه‌های اعلان را دارند.
تست APK امضاشده، **IPC و deep-link واقعی کد تولید** را به یک APK فروشگاهِ مصنوعیِ جدا
در امولاتور می‌برد؛ فروشگاه ساختگی شبکه/دانلود/نصب ندارد، به کاربر تحویل نمی‌شود و پاسخ
قدیمی/جدیدش عمداً متفاوت است تا انتخاب متد مدرن بررسی شود. این تست، آزمون زندهٔ بازار،
تأیید انتشار حساب مالک یا تضمین دانلود آینده از بازار نیست.
