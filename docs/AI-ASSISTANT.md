# دستیار خودرویار — 5.1.11

## انتخاب درست اتصال

| حالت | نیازمندی | درخواست شبکه | قالب پاسخ |
|---|---|---|---|
| داخلی — بدون API (پیش‌فرض) | هیچ کلید/سرور/اینترنتی لازم نیست | هیچ | دادهٔ واقعی ابزارهای محلی |
| اتصال مستقیم GapGPT | کلید شخصی واقعی، اینترنت و اعتبار حساب | `POST https://api.gapgpt.app/v1/chat/completions` یا CDN انتخابی | `choices[0].message.content` |
| بک‌اند شخصی خودرویار | سرور مستقرشدهٔ `backend/`، کلید مدل روی آن سرور، توکن اختیاری بک‌اند | `POST <backend>/v1/chat` | `{content, model}` |

**این دو حالت آنلاین پروتکل یکسانی ندارند.** نصب کتابخانهٔ Python در برنامهٔ Kotlin لازم نیست؛ پیاده‌سازی HTTP مستقیم باید همان مسیر، هدر، بدنه و پاسخ SDK را رعایت کند. جزئیات مقایسه با نمونهٔ ارسالی کاربر: `CHANGES_5.1.11.md`.

## راه‌اندازی مستقیم مطابق نمونهٔ GapGPT
1. دستیار ← تنظیمات ← **اتصال مستقیم GapGPT**.
2. آدرس اصلی `https://api.gapgpt.app/v1` یا CDN خارجیِ معرفی‌شده `https://api.gapapi.com/v1` را انتخاب کنید.
3. مدل `gpt-4o` یا نام مدل مجاز حساب خود (مثلاً `gemini-2.5-pro`) را وارد کنید. فهرست نام‌ها تضمینِ دسترسی حساب شما نیست.
4. API Key واقعی خود را **فقط در فیلد API Key برنامه** وارد کنید؛ نه در چت، نه در فیلد توکن بک‌اند. عبارت `YOUR_GAPGPT_API_KEY` فقط جای‌نگهدار راهنماست.
5. ذخیره و تست واقعی را بزنید و رضایت ارسال را تأیید کنید. این تست یک پیام سلام و سقف خروجی ۳۲ توکن دارد و ممکن است از اعتبارتان کم کند؛ تاریخچه یا دادهٔ مالی نمی‌فرستد. مسیر واقعی درخواست در نتیجهٔ تست دیده می‌شود.

کلید با Android Keystore و EncryptedSharedPreferences در فایل خصوصی مجزا رمزنگاری می‌شود؛ داخل APK، BuildConfig، Room، تاریخچه، خروجی یا بکاپ نیست. فیلد رمز خالی، کلید ذخیره‌شده را نمایش نمی‌دهد و هنگام ذخیره حفظش می‌کند. دکمهٔ حذف کلید برای پاک‌کردن از گوشی وجود دارد. خطای رمزنگاری به ذخیرهٔ متن ساده منجر نمی‌شود. برای توزیع عمومی اپ با اعتبارِ مالک، از حالت بک‌اند استفاده کنید، نه قرار دادن کلید مشترک در APK.

بازکردن صفحه یا ذخیرهٔ تنظیمات تست هزینه‌دار را خودکار اجرا نمی‌کند. تا پاسخ واقعی نیاید فقط «تنظیم شده — اتصال آزمایش نشده» نمایش داده می‌شود. هیچ Redirect یا تغییر خودکار به CDN دیگر حامل کلید انجام نمی‌شود. فقط دو میزبان رسمیِ معرفی‌شده در نمونه مجازند.

### عیب‌یابی ۴۰۴
- اگر آدرس GapGPT را در فیلد **بک‌اند خودرویار** وارد کنید، اپ قبل از شبکه جلوی آن را می‌گیرد و انتخاب حالت مستقیم را پیشنهاد می‌کند. نسخهٔ قبلی این آدرس را به `/v1/chat` اشتباه وصل می‌کرد.
- مستقیم باید `POST /v1/chat/completions` باشد؛ نه `/v1/chat`، نه `/v1/status` و نه `/v1/v1/...`.
- اگر همین مسیر صحیح باز هم ۴۰۴ بدهد، نام مدل، دسترسی حساب و وضعیت سرویس/میزبان را بررسی کنید. خطای `model_not_found` جدا از مسیر ناموجود نمایش داده می‌شود. بدون پاسخ واقعی نمی‌توان همهٔ ۴۰۴ها را به یک علت نسبت داد.
- ۴۰۱/۴۰۳: کلید و مجوز حساب؛ ۴۰۲ یا quota: اعتبار؛ ۴۲۹: محدودیت؛ HTML یا JSON نامرتبط حتی با HTTP 200 اتصال موفق نیست.
- برای گزارش خطا فقط متن خطا، نام مدل، حالت اتصال و آدرس عمومی را بفرستید؛ **هرگز API Key یا Authorization را نفرستید**.

## حالت داخلی

```
UI → ViewModel → LocalAssistant → LocalIntentParser
                      └→ AgentActionValidator → AgentApprovalGate → AgentToolExecutor → AppRepository (Room)
```

دستیار دستورمحور است، **نه مدل زبانی عمومی**. بدون اینترنت، مدل دانلودی، کلید یا سرویس ناشناس کار می‌کند. `راهنما`، `گزارش این ماه`، `وضعیت خودرو`، `ثبت هزینه قهوه ۵۰ هزار تومان` یا `ثبت سوخت ۴۰ لیتر ۱۲۰ هزار تومان` را امتحان کنید. ثبت هزینه/تعمیر/نگهداری/سوخت و یادآور تأیید لازم دارند. ویرایش/حذف متنی، ثبت سفر/درآمد و سؤال عمومی در این حالت پشتیبانی نمی‌شوند. راهنمای کامل در `CHANGES_5.1.10.md` است. اگر نفهمد، حدس نمی‌زند و به اینترنت هم fallback نمی‌کند.

## ایمنی مشترک و معماری آنلاین

```
UI → ViewModel → AiProviderRouter → backend protocol OR direct Chat Completions
                      └→ AgentOrchestrator → Validator → ApprovalGate → Executor → Repository
```

پیام کاربر حداکثر ۱۰۰۰ نویسه، تاریخچهٔ ارسالی حداکثر ۱۰ پیام/۶۰۰۰ نویسه، نتیجهٔ ابزار ≤۳۰۰۰ نویسه، هر درخواست ≤۵ گام و خروجی مدل ≤۷۰۰ توکن است. مدل فقط ابزارهای تعریف‌شده را درخواست می‌کند؛ SQL، shell و فایل دلخواه ندارد. READ فوری است؛ WRITE و DELETE فقط بعد از خلاصهٔ معتبر و تأیید کاربر، حذف با تأیید قرمز. نتیجهٔ واقعی با بازخوانی دیتابیس نمایش داده می‌شود.

حالت، کلید/حساب یا مقصد که عوض شود رضایت بازنشانی و گفتگو جدا می‌شود. تاریخچهٔ حالت محلی، مستقیم و بک‌اند جداست؛ سابقهٔ محلی بی‌اطلاع به آنلاین منتقل نمی‌شود. مدل/سرویس فقط متن و نتایج مرتبط ابزارها را می‌گیرد، نه پرسنل/تلفن، موقعیت، مخاطبین، پیامک، فایل‌ها، PIN یا کلیدهای دیگر. خطاهای خام و هدرهای محرمانه لاگ نمی‌شوند. Room همچنان نسخهٔ ۶ است.

تست‌های JVM شبکه را شبیه‌سازی می‌کنند؛ تست Node نیز Mock است. بیلد/امضا و آزمون شبیه‌سازی‌شده جای آزمایش حساب واقعی یا گوشی را نمی‌گیرند. مصرف سوخت همچنان تخمینی و بر اساس کیلومتر سرویس‌های ثبت‌شده است.
