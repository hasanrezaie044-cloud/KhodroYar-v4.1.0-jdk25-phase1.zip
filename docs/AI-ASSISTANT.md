# دستیار خودرویار — 5.1.10

## حالت داخلی (پیش‌فرض، بدون API)

```
AiAssistantScreen → AiAssistantViewModel → LocalAssistant → LocalIntentParser
                                              │
                                              └→ AgentActionValidator → AgentApprovalGate → AgentToolExecutor → AppRepository (Room)
```

این حالت یک **دستیار دستورمحور محلی** است، نه مدل زبانی مولد/عمومی. هیچ کلید API، حساب، سرور، اینترنت یا دانلود مدل لازم نیست. برای وضعیت و «تست اتصال» محلی هم درخواست شبکه ساخته نمی‌شود. برنامه بی‌اطلاع کاربر به یک API عمومیِ ناشناس متصل نمی‌شود.

`راهنما` نمونه‌ها و محدودیت‌ها را نشان می‌دهد. میانبرهای گزارش ماه، وضعیت خودرو و راهنما در صفحهٔ خالی هستند. نمونه‌های ثبت/گزارش و جزئیات تغییرات در `CHANGES_5.1.10.md` آمده‌اند.

- گزارش ماه/سال/کل، هزینه‌های امروز، فهرست سوابق، مصرف تقریبی سوخت، وضعیت خودرو و یادآورها از دیتابیس واقعی خوانده می‌شوند؛ عدد ساختگی نیست.
- ثبت هزینه، تعمیر/نگهداری، سوخت و یادآور فقط پس از تأیید انجام می‌شود. ویرایش/حذف متنی، ثبت سفر/درآمد، سؤال عمومی، گزارش هفته/دیروز و تاریخ مبهم در این حالت پشتیبانی نمی‌شوند؛ از صفحات اصلی برنامه استفاده کنید.
- عددهای فارسی/عربی به لاتین تبدیل می‌شوند. مبلغ صریح با تومان/ریال لازم است؛ عددهای حروفی پشتیبانی‌شده شامل `دو میلیون و پانصد هزار` یا `یک و نیم میلیون` هستند. عبارت مبهمی مثل `دو میلیون و نیم` حدس زده نمی‌شود.
- اگر درخواست فهمیده نشود، راهنما می‌دهد؛ هرگز برای «حدس بهتر» اطلاعات را به اینترنت نمی‌فرستد.

## حالت آنلاین (اختیاری)

```
UI → ViewModel → AgentOrchestrator → GapGPTProvider → HTTPS backend → GapGPT
                       │
                       └→ AgentActionValidator → AgentApprovalGate → AgentToolExecutor → AppRepository
```

در تنظیمات «آنلاین — سرور شخصی» را انتخاب و آدرس بک‌اند خودرویار را وارد کنید. کلید سرویس مدل فقط در Environment بک‌اند است؛ توکن اختیاری اپ با API Key فرق دارد. سرویس آنلاین رایگان/نامحدود فرض نشده است.

### مسیرها و خطای ۴۰۴
آدرس `https://server.example`، `https://server.example/v1` و `https://server.example/v1/chat` همگی به یک درخواست `POST /v1/chat` تبدیل می‌شوند. پیشوندی مثل `/assistant` حفظ می‌شود. آدرس باید **بک‌اند همین پروژه** باشد، نه GitHub Pages، صفحهٔ وب، آدرس مستقیم GapGPT یا یک OpenAI API عادی. قرارداد پاسخ این بک‌اند `{content, model}` است، نه `{choices: ...}`.

- `۴۰۴ بک‌اند`: آدرس/استقرار/مسیر پراکسی را بررسی کنید؛ صرف داشتن Secretهای امضای APK یک سرور AI مستقر نمی‌کند.
- `upstream_not_found` (۴۰۴ ارائه‌دهنده): `GAPGPT_BASE_URL` و نام مدل روی سرور بررسی شوند. ممکن است مسیر API یا مدل اشتباه باشد؛ فقط با کد ۴۰۴ نمی‌توان یکی را قطعی دانست.
- تنظیم بک‌اند آدرس ریشه یا Endpoint کامل Chat Completions را می‌پذیرد و `/chat/completions` را دو بار اضافه نمی‌کند.
- پاسخ HTML یا JSON نامرتبط موفقیت محسوب نمی‌شود. دکمهٔ ادامه با حالت داخلی حتی بدون رفع تنظیمات آنلاین، امکانات محلی را در دسترس می‌گذارد.

### حریم خصوصی و جریان درخواست
قبل از تست/ارسال آنلاین رضایت لازم است. حداکثر ۱۰ پیام اخیر / ۶۰۰۰ نویسه همراه تاریخ شمسی و فهرست ابزارها فرستاده می‌شوند. نتیجهٔ ابزار ≤۳۰۰۰ نویسه و هر درخواست ≤۵ گام است. حداکثر پیام کاربر ۱۰۰۰ نویسه و خروجی مدل ۷۰۰ توکن است.

مدل یک JSON `reply` یا `tool` می‌دهد؛ متن ساده فقط نمایش داده می‌شود. ابزارهای READ فوراً خوانده می‌شوند؛ WRITE/DELETE با خلاصهٔ معتبر برنامه و حذف با تأیید قرمز متوقف می‌شوند. فقط ابزارهای تعریف‌شده مجازند، نه SQL یا فرمان دلخواه. نتیجهٔ ثبت پس از بازخوانی دیتابیس گزارش می‌شود.

فقط متن گفتگو و نتایج مرتبط ابزارها ممکن است ارسال شوند؛ نه پرسنل/تلفن، موقعیت، مخاطبین، پیامک، فایل‌ها، PIN یا کلیدها. تغییر حالت/سرور رضایت را بازنشانی می‌کند. تاریخچهٔ دو حالت جداست؛ سابقهٔ محلی به آنلاین ارسال نمی‌شود. گفتگوهای نسخهٔ قدیمی آنلاین باقی می‌مانند. Room و بکاپ‌های اصلی تغییری نکرده‌اند.

## دقت و آزمون
مصرف سوخت بر اساس کیلومتر سرویس‌های ثبت‌شده است و الزاماً کیلومتر واقعی خودرو نیست. منطق مسیر، خطا، پارسر و تأیید عملیات JVM Unit test دارد؛ شبکهٔ بک‌اند با Mock تست می‌شود. موفقیت بیلد جای آزمایش روی گوشی یا اتصال به GapGPT واقعی را نمی‌گیرد.
