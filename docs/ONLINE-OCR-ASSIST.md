# پیش‌پر اختیاری آنلاین گزارش کارکرد — قرارداد سرویس

پردازش گزارش کارکرد به‌صورت پیش‌فرض و همیشه **کاملاً آفلاین** است. دکمهٔ «پیش‌پر اختیاری آنلاین»
فقط با تأیید صریح کاربر فعال می‌شود و تصاویرِ همان دوره را یک‌بار به نشانی HTTPS انتخاب‌شدهٔ کاربر
می‌فرستد. این ویژگی برای کاربرانی است که سرور OCR قوی‌ترِ خودشان را دارند؛ مسئولیت حریم خصوصی،
نگهداری و حذف داده‌ها در سمت گیرنده بر عهدهٔ کاربر است.

## ضمانت‌های سمت برنامه (تغییرناپذیر)

- بدون تأیید صریح همان‌بار، هیچ بایتی ارسال نمی‌شود؛ دکمه میزبان گیرنده را پیش از ارسال نشان می‌دهد.
- هر POST حداکثر ۱۰ صفحه دارد و هر صفحه حداکثر ۱٫۲ مگابایت JPEG است (با کاهش مقیاس/کیفیت محدود می‌شود).
- پاسخ فقط جدول **بازبینی** را پیش‌پر می‌کند: هیچ سرویسی خودکار ثبت نمی‌شود، هیچ خانهٔ خالی/نقطه/خط‌تیره‌ای
  پر نمی‌شود، هیچ صفر ساختگی وجود ندارد، تضادهای قوی خالی می‌مانند و مقایسهٔ سخت‌گیرانهٔ همان قبلی است.
- فقط HTTPS؛ بدون دنبال‌کردن redirect؛ بدون کوکی؛ پاسخ حداکثر ۲ مگابایت. خطای شبکه هیچ داده‌ای را تغییر نمی‌دهد.

## درخواست

`POST <endpoint>` با بدنهٔ JSON و `Content-Type: application/json; charset=utf-8`:

```json
{
  "version": 1,
  "pages": [
    { "id": "<شناسهٔ صفحهٔ برنامه>", "mime": "image/jpeg", "pixels": 4736000, "image_base64": "..." }
  ]
}
```

## پاسخ مورد انتظار

```json
{
  "pages": [
    { "id": "<همان شناسه>", "words": [
      { "text": "۱۴۰۳/۰۴/۱۲", "left": 0.70, "top": 0.30, "right": 0.90, "bottom": 0.34, "confidence": 96 }
    ] }
  ]
}
```

- مختصات نرمال‌شدهٔ [0..1] نسبت به همان تصویر ارسالی؛ کلمات بیرون محدوده/نامعتبر حذف می‌شوند.
- confidence عددی ۰ تا ۱۰۰؛ برنامه آن را به همین بازه محدود می‌کند.
- فرمت تاریخ پشتیبانی‌شده: شمسیِ جداشده با `/` `-` `.` یا هشت‌رقمی فشرده؛ ارقام فارسی/عربی/لاتین.
- برای ردیف‌های جدول شرکت، کلمات با مرکز داخل همان خانهٔ خط‌کشی‌شده به‌کار می‌روند؛ در غیر این صورت
  همان خانه دوباره فقط با Tesseract محلیِ تصویرِ ارسال‌شده خوانده می‌شود (یعنی سرویس می‌تواند فقط
  کیفیت تصویر را ارتقا دهد و words خالی برگرداند).

سرویس غایب یا نامعتبر = همان رفتار آفلاین قبلی: خانه‌های ناخوانا برای ورود دستی خالی می‌مانند.
