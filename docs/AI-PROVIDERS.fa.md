وضعیت این جدول **بازبینی اسناد رسمی و پیاده‌سازی/mock است، نه آزمون حساب زنده**. رایگانِ محدود، trial با کارت و سرویس پولی یکسان نیستند. sandbox، mock یا قابل‌دسترسی‌بودن وب‌سایت، اثبات مجوز استفادهٔ ایران نیست. قیمت/فهرست ممکن است تغییر کند؛ بدون شواهد معتبر و رضایت ارسال نمی‌کنیم. هیچ خرید، billing، کارت یا اعتبار واقعی در این کار فعال/استفاده نشده است.

## نکات انتخاب مدل و هزینه

- OpenRouter router تصادفی `openrouter/free` برای انتخاب ثابت/آزمون قابل انتساب فعال نمی‌شود. مدل مشخص فقط با ID دقیق و شواهد قیمت/مجوز/endpoint تازه، نه با حدس پسوند یا نام نمایش، پذیرفته می‌شود.
- مدل‌های quota-based روی حساب paid می‌توانند هزینه داشته باشند. برنامه API معتبری برای تشخیص قطعی plan در Groq/Gemini ندارد؛ هشدار و تأیید صریح Free بدون billing از مالک می‌گیرد و ادعای صفرصورتحساب نمی‌کند. حساب دارای billing را متصل نکنید. Cloudflare حتی پس از تأیید مالک، شواهد API طرح را نیز مطالبه می‌کند.
- سهمیه، سرعت و کیفیت فارسی با mock معلوم نمی‌شوند. ارزیابی اختیاری و محدود، تنها با درخواست و هشدار مصرف است. «بررسی اتصال» فقط فراداده است و موفقیت inference زنده محسوب نمی‌شود.
- Gemini۲.۵Pro/Flash در سند deprecated و با تغییر مسیر/نرخ از۲۰۲۶-۱۲-۰۱ معرفی شده‌اند؛ در allowlist این نسخه نیستند. مدل‌های paid/تصویری/grounding/جستجوی وب/اجرای کد فعال نیستند. Gemini۴Carbon/Argon رایگان اعلام نشده‌اند و هرگز انتخاب نمی‌شوند. allowlist کوچک عمدی است، نه فهرست همهٔ مدل‌های بازار.
- هر سرویس محدودیت منطقه/صادرات/شرایط داده دارد؛ IP یا موقعیت کاربر جمع نمی‌کنیم. تأیید دستی منطقه مجاز، راهنمای دورزدن نیست. قید زمانی سیاست مستقیم تا۲۰۲۶-۱۲-۱۰ است؛ انقضا به‌جای ادامه با شرایط کهنه، ارسال را می‌بندد.
- تاریخ بازبینی، زمان مشاهدهٔ سند است؛ هیچ cache وب یا برچسب «آخرین به‌روزرسانی» جای تأیید حساب واقعی نیست. صفحهٔ Cloudflare در پاسخ وب برچسب۲۰۲۶-۱۱-۱۲ داشت که بعد از تاریخ این بازبینی است؛ بنابراین آن برچسب به‌عنوان سند آزمون امروز یا تضمین حساب استفاده نمی‌شود.
